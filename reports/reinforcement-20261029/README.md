# 6면 동일 ID 태그 보강 실험 — 2026-10-29

## 변경 사항과 데이터 계약

- 사용자의 눕힌 직육면체 설정을 유지하고 6면 중앙에 같은 tag36h11 ID를 부착. 원기둥은 기존 윗면 태그.
- 같은 물체의 여러 태그 면 검출을 단일 물체 ID로 연결. 가장 큰 영상 면적의 태그가 대표이며 전체 면은 `tags`에 유지.
- 같은 ID로는 면을 식별할 수 없어 태그 기반 물체 중심은 확정하지 않고 두 법선 이동 후보를 반환. CenterPose 중심은 별도 학습 예측.
- 단일면 자료의 기존 모델·데이터는 보존. 첫 단일면 추가 학습은 6면 부착 사양 확인 시 중단했으며 최종 모델에 사용하지 않음.

## 기존 평가의 한계 및 수정

기존 `data/tagged-test`는 train 8000장, val/test 각 1000장이었으나 생성기의 고정 seed 시작값 1000/3000/5000 때문에 train과 val/test 각각 1000개 seed가 겹쳤습니다. 과거 평가를 독립 시험으로 해석할 수 없습니다. `baseline-audit.json`에 중복과 클래스별 태그 검출 수를 기록했습니다.

새 생성기는 split 수량에 따라 인접한 비중복 seed 구간을 배정합니다. 이번 6면 데이터는 300000~301699를 사용했습니다. 이전 학습 자료의 seed와도 겹치지 않습니다. 단, 동일한 절차적 장면 생성기·카메라 분포의 시험이며 실물 일반화 증거는 아닙니다.

## 실행과 모델 선택

`prepare-sixface-data.py`는 기존 train 중 고정 seed로 400장을 선택해 새 6면 train 1200장과 합칩니다. val 200장/test 300장은 모두 새 6면 자료입니다. 기존 자료는 복사·변경하지 않고 절대 이미지 경로로 참조합니다.

`run-training.sh`는 CenterPose 12 epoch, batch16, lr=0.00005 미세조정 후 YOLO 8 epoch, batch4, AdamW lr0=0.0001 미세조정을 실행합니다. CenterPose는 초기 모델의 새 val loss도 측정하고 더 나은 경우만 best.pt를 갱신합니다. YOLO는 동일 val에서 기존/후보 모델 mAP50–95를 비교해 높은 모델을 선택합니다. test 결과를 보고 모델을 고르지 않습니다.

`baseline-sixface/evaluation.json`과 `final-sixface/evaluation.json`은 동일한 새 test 300장의 전체 프레임 기록이며 로컬에 보존합니다. Git에는 프레임을 제외한 요약과 감사 기록을 저장합니다. 태그 위치 평가에서는 예측으로 대표 면을 선택한 뒤 해당 면의 GT 코너와 비교합니다. 6면 태그의 중심 후보를 정답으로 선택해 물체 중심 오차를 낮추지 않습니다.

## 검증

- 단위 테스트 25개: 기존 pose 검사, 동일 ID 여러 면 연결/여러 물체 중복 거부, 8000/1000/1000 seed 비중복 회귀 검사 포함.
- 신규 1700개 YOLO 라벨 형식 검사 통과.
- smoke 렌더에서 클래스별 태그 수 1/6/1/6, 네 물체 ID 검출 확인.
- 56개 태그 면의 정답 좌표 검사: 검은 경계 16mm, 중심 거리 15.03 또는 30.03mm 확인.

실시간에서 새 구성은 `--prism-tag-mount six_faces`를 지정해야 합니다. 파일 추론은 manifest에서 자동으로 읽습니다.
